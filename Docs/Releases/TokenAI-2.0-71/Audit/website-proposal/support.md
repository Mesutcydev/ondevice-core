# Token: Local AI Studio — Support

Token 2.0 requires an iPhone with iOS 27 or later and supports iPhone Duo. Compatible model packs are downloaded separately; available features depend on the selected model and device resources.

## Getting started
Complete onboarding and legal acceptance. Open the leading menu, choose Models, then Discover. Download a compatible model, activate it in Assistant, and start a conversation. Lens, voice and Image Studio require their own compatible models.

## Downloads and storage
Use a reliable network for model downloads. Models can require several gigabytes of free space. Manage downloads, imports and storage in Models; compatibility depends on memory, storage and thermal conditions.

## Voice, photos and camera
Start the feature you want to use and allow its requested iOS permission. Camera, microphone, Photos and speech access are controlled in iOS Settings. Voice and vision availability depend on the selected engine and model.

## Optional network features
Local models run on the device. Web tools, custom API providers, the local API server and Mac pairing are optional and have separate controls. Review the privacy policy before enabling them.

## Diagnostics and data
Diagnostics remain local unless you explicitly export them. Review a report before sharing it. Delete local chats, models, saved content or use the confirmed Wipe All Data control in Settings. Exported copies and backups are managed separately.

## Contact
Use the site's existing contact route at https://mesut.uk/contact. The app's privacy policy is https://mesut.uk/apps/token/privacy. Do not send API keys, private tokens or sensitive conversation content in a support request.
