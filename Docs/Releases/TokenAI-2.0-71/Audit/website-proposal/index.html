Token: Local AI Studio

Token AI brings a local AI workspace to your iPhone. Download compatible models, choose the right one for your task, and keep your conversations organized in one place.

CHAT AND CREATE
Ask questions, draft writing, review code and explore ideas. Start a new conversation or return to a saved chat, with search and pinned conversations to help you find your work.

VOICE AND VISION
Choose a voice for spoken conversations. Use compatible vision models to work with photos and camera captures in Lens.

YOUR MODEL LIBRARY
Browse available models, download compatible packs, import supported model files and manage the storage they use. Model availability depends on your iPhone and the model's requirements.

IMAGE STUDIO
Create images using supported local image models. Image models are downloaded separately. Optional parental controls let a parent restrict image generation with a PIN.

LOCAL API
Enable the authenticated Local API Server to connect compatible tools on your trusted local network.

LOCAL BY DEFAULT
No Token AI account is required. Conversations are stored on your device and compatible models run locally. Optional web tools send requests to the provider you configure. Optional iCloud conversation sync uses your private CloudKit database.

Requires iOS 27 or later. Model files are downloaded separately and may require several gigabytes of storage. Available features, model compatibility and generation speed depend on your iPhone's memory, storage and thermal conditions. AI results can be inaccurate; review them before relying on them.
