# Token AI 2.1.3 App Store text

`copy.json` contains the What's New and promotional text written on 2026-10-31
to the 11 existing localizations of App Store version 2.1.3
(`c1d7ce10-b35d-4892-a2cf-767e3dbd385c`, PREPARE_FOR_SUBMISSION). The text
describes what TestFlight 2.1.3 (95) adds over the live 2.1.2: LFM3 Omni 2B,
video in chat, Lens → Clip, Omni speech-to-text and voice, whole-document PDF
summaries, and chats that no longer download a missing model. UI names follow
the app's translations (Models, Clip).

`before.json` records the original (empty) values and localization IDs;
`upload-results.json` records the update results; and `verified.json` records
the App Store Connect read-back comparison. All 11 updates matched and the
description, keywords, marketing URL, and support URL remained unchanged.
No build was attached and no review was submitted by this work.
